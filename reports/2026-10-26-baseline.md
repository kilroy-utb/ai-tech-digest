## 摘要

這是本 repo 的第一份基準報告，確立「每個數字都可追溯到官方端點」的原則。

五個關鍵發現：

1. **Agent 生態的體量已超越模型本身** — OpenClaw 393k stars、Anthropic 官方 Agent Skills 184k、superpowers 305k、Claude Code 153k。Skill 已成為獨立的一等公民，不是附加功能。
2. **MCP 完成規格世代交替** — `2026-07-28` 為 stable 版，官方 servers 從 legacy era（v1.0.0）完整遷移到 modern era（v2.0.0）。
3. **GGUF 是本地部署的絕對主流量化格式** — 在 608 個熱門模型 repo 中佔 32.4%，遠超 MLX (5.4%)、NVFP4 (3.3%)、FP8 (1.5%)、AWQ (0.7%)。
4. **社群 fine-tune 的下載量仍低於官方量化路徑** — 這是重要的反面證據：本機跑的 `HauhauCS/...-Aggressive-MTP-GGUF` 有 231 萬下載，但 `unsloth/Qwen3.8-27B-GGUF` 官方 GGUF 有 586 萬、`ggml-org` 官方 226 萬。
5. **MiniMax M3.1 確實存在** — Ollama 官方 library 已收錄 `minimax-m3.1-flash`，而本機 `config.yaml` 仍指向 `MiniMax-M3`（fallback `M2.7`）。

## 2. Local LLM 與量化

### 2.1 量化格式分佈（608 個熱門模型 repo，HuggingFace API）

| 格式 | 數量 | 佔比 | 適用情境 |
|---|---:|---:|---|
| (無量化標記 / base) | 325 | 53.5% | 官方原始權重，通常是 BF16/FP16 |
| **GGUF** | **197** | **32.4%** | llama.cpp / Ollama 生態，通用性最高 |
| MLX | 33 | 5.4% | Apple Silicon 專用 |
| NVFP4 | 20 | 3.3% | NVIDIA Blackwell 硬體原生 4-bit |
| BF16 | 10 | 1.6% | 訓練/基準用全精度 |
| FP8 | 9 | 1.5% | Hopper+ GPU 推論 |
| QAT | 7 | 1.2% | 量化感知訓練（Google gemma-4 走這條路） |
| AWQ | 4 | 0.7% | vLLM 生態，4-bit weight-only |
| INT8 / 4bit / MXFP4 | 各 1 | ~0.2% | 少量 |

**結論**：GGUF 是本地部署事實上的唯一通用選擇。MLX 只在 Mac 上有意義，NVFP4/FP8 需要特定硬體，AWQ 只在 vLLM 生态。
