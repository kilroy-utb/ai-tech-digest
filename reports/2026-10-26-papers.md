## 趨勢觀察

### 1. 量化從「單一方法競賽」轉向「部署導向的系統工程」
這批論文罕見地各自附帶推論 kernel 與真機測試：MpFA（B200 輸出吞吐 2.81x）、FuTransformer（Llama-3.1-8B 每步 2.8ms）、FIGFLEX（每面積吞吐 1.56x）、QuantMLA（自製低 bit MLA kernel）。

另一條主線是**「去特例化」** — JustQuant 主張 4-bit activation 不需要 smoothing/SVD/rotation，Disaggregated Quantization 主張 prefill 與 decode 該用不同格式，SpecQuant 主張量化變體本身就是 draft model。

### 2. 低精度正在從「推論期」反攻「訓練期」
QATFactory、What Matters for NVFP4 Training 一致顯示 4-bit（NVFP4/MXFP4）已能撐住大規模 pre-training 與 RL 訓練，關鍵在於**分層精度配置、去偏梯度估計與跨引擎數值一致性**。

### 3. KV cache 儼然成為系統設計的主戰場
議題從「怎麼壓」轉向「**怎麼搬、怎麼找、怎麼排**」：
- 壓縮面：Distance-KV（把相對距離當結構）
- 搬運面：PulseInfer（I/O 瓶頸）、TempoKV（staging 時機）、TierKV（行動裝置三層預測）
- 排序面：When the KV Cache Is Slower Than the GPU — 用**負面結果**證明「命中未必勝過重算」

### 4. 推論效率的終點是「排程與模擬」而非單一 kernel
vSkipper 讓 per-token 層跳過真正在 SGLang 裡換到 36.8% 延遲下降；SlimWise 為 MoE 把 prefill 與 decode 的 expert pruning 解耦；**BLIS 用純 CPU 離散事件模擬器以 6.7% 誤差、200 倍速度做部署規劃並合入 llm-d**。

### 5. PEFT 的重心從「新的 adapter 變體」轉向三個結構性問題
- **初始化的幾何結構**：GDLoRA（切空間限制）、initAA（初始化噪聲）
- **套用的位置**：LS-LoRA（層選擇比全層適應更有效）
- **與推論系統的耦合**：PACT（消費級 GPU）、MOLT（serving + 訓練 colocate）

### 6. 「Harness」正式成為獨立研究對象
2026-10 一週內出現 HarnessMM、TraceTrial-Bench、Training the Whole Agent 一批論文。共同論點：**agent 的能力不只由 model 決定，harness 同樣是瓶頸**。多篇實測顯示模型「看到了問題卻仍照錯方向做」。

### 7. Agent Skill 生態已進入「管理與退場」階段
SkillClash 揭示 skill 間的規則衝突與 takeover、One-File Fix 給出合併解法、Skill Internalization 定義退休判準、SkillGrain 做選擇性保留、EvoSkill v2 讓 skill 自我演化、Adaptive Skill Granularity 引入 runtime routing。

**Skill 正從「靜態文件」變成「可控、可驗證、可恢復的執行抽象」**。

### 8. 記憶管理的重心從「存」轉向「何時存、何時取、何時忘、付多少錢」
MemoryTax 直言 agent memory 對強模型是昂貴補丁且有 writer 天花板；MemDev-Bench 發現 agent 會盲目重用記憶而導致原本可解的任務失敗；Cortex 則走另一條路，把 context 蒸餾進參數記憶。

### 9. Context 管理已從「摘要」升級到「KV cache 操作」與「compaction 代價量化」
Cache Engineering 指出摘要式 context engineering 會破壞 cache 複用；**Compact-Bench 量化 compaction 對長程任務的真實損傷（LLM 摘要只保留 16% recurring detail，機械式抽取可達 79.1%）**。

### 10. 多 agent 協商從「能不能共識」轉向「共識如何形成、誰在主導、權限如何劃界」
Who Is the Influencer 發現大模型會吸收其他模型意見成為 influencer；Herding 研究顯示 LLM 族群比人類更易從眾且難自我糾正；**Show-Up Attack 揭示 subagent 可越權影響 supervisor（GPT-5.6-Sol 作為 supervisor 時 ASR 0.93）**。

**多 agent 系統的下一個戰場是治理與邊界，不是單純堆 agent 數量。**

### 11. 「評估誠實度」成為顯著的方法論貢獻
vSkipper 揭露 FlexiDepth 的層跳過在其原生迴圈中反而慢 14.6–21.0%；Cartridges++ 揭露 CKV 方法在 off-context 查詢上的落差；When the KV Cache Is Slower Than the GPU 用 83.32s p99（GPU 僅 7% 忙碌）說明遠端 KV tier 可能有害；edge 可持續性比較直接推翻「SLM 必然更可持續」的常見假設。

**這類把負面結果與量測方法一起交付的工作，在同期論文中相對稀缺。**
